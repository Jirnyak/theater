## 📖 About

**CYBER-THEATER** is an experimental creative-coding engine designed to power interactive live visual performances, generative art installations, and audio-reactive stage experiences. Think: code as theater. The audience is inside the machine.

---

## ✨ Features

- 🎨 **Real-Time Generative Visuals** — procedurally animated scenes that evolve live on stage
- 🔊 **Audio Reactivity** — FFT-based sound analysis drives visual morphing and intensity
- 💡 **Dynamic Stage Lighting Simulation** — programmable virtual stage lights with physics-based diffusion
- 🎭 **Scene Scripting API** — write theatrical scenes in plain JavaScript
- 🌐 **Browser-First** — runs in any modern browser, no plugins
